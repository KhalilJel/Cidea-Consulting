# AI agent vs chatbot: what's the difference?

A chatbot is usually built to communicate with a user. An AI agent can, to a greater extent, be given a goal, use tools and carry out several steps in a workflow.

## Why the difference matters

If the need is simply to answer common questions, a chatbot may be enough. If the task requires research, decisions, tools and action across systems, an agent system may be more relevant.

## Start with the workflow

The most important question isn't which AI technology to buy. It's which workflow you want to improve.

From there, you can choose the right level of automation.
