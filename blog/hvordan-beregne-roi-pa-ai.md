# Hvordan beregne ROI på AI?

AI bør vurderes som et forretningsprosjekt, ikke bare som et teknologiprosjekt. Før du investerer bør du forstå hvilket problem som skal løses og hvilken verdi løsningen kan skape.

## Start med dagens situasjon

Kartlegg hvor mye tid, penger eller kapasitet som brukes på prosessen i dag. Se også på feil, ventetid og manuelt arbeid.

## Estimer potensiell gevinst

En enkel vurdering kan sammenligne forventet tidsbesparelse, redusert kostnad eller økt kapasitet med kostnaden ved å bygge og drifte løsningen.

## Ta med kompleksitet og risiko

En løsning med høy teoretisk gevinst er ikke nødvendigvis et godt første prosjekt. Datakvalitet, integrasjoner, sikkerhet, menneskelig kontroll og endringer i arbeidsprosesser påvirker den reelle verdien.

## Prioriter de beste mulighetene

Start med use cases der problemet er tydelig, verdien kan måles og gjennomføringen er realistisk. Deretter kan virksomheten bygge videre på det som faktisk fungerer.
